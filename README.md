# Madhav-E-Commerce-Sales-Dashboard
An interactive Power BI dashboard designed to analyze and visualize e-commerce sales performance.
Key Insights
- Sales, Profit, Quantity and AOV KPIs
- State-wise sales analysis
- Customer-wise performance
- Category and sub-category analysis
- Payment mode analysis
- Profit and sales trends
- Interactive slicers and filters

### Tools & Technologies
- Power BI
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization
